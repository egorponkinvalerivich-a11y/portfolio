# VALDI V4

Финальный адаптивный лендинг бренда VALDI по утверждённому ТЗ.

## Структура
- `index.html` — страница
- `assets/css/styles.css` — стили и адаптив
- `assets/js/app.js` — анимации, меню, FAQ и окно заказа
- `assets/img/` — оптимизированные WebP-фотографии и прозрачный логотип

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите всю папку на хостинг без изменения структуры.
